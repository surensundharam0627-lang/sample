# 🚀 Python Alone Render Showcase Project

A 100% pure Python web application built with **FastAPI** & **Uvicorn**, designed to showcase how to host a standalone Python project on [Render.com](https://render.com) and get a live public Render URL (`https://<your-app-name>.onrender.com`).

---

## 📁 Project Structure

```text
python-render-demo/
├── app.py              # Pure Python FastAPI web application & REST endpoints
├── requirements.txt    # Python dependencies (FastAPI, Uvicorn, Gunicorn)
├── Procfile            # Deployment command for Render/Heroku web services
├── render.yaml         # Render Blueprint configuration file (1-click deploy)
├── runtime.txt         # Specifies exact Python runtime version
└── README.md           # Instructions & documentation
```

---

## 🛠️ Step 1: Run & Test Locally

Before pushing to GitHub or deploying to Render, test the application on your local machine:

1. **Navigate to the project folder:**
   ```bash
   cd python-render-demo
   ```

2. **Create a Python Virtual Environment & Activate it:**
   - **Windows:**
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - **Mac/Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Start the Web Server:**
   ```bash
   uvicorn app:app --reload --port 8000
   ```

5. **Open in Browser:**
   - App UI: `http://127.0.0.1:8000/`
   - Interactive OpenAPI Docs: `http://127.0.0.1:8000/docs`
   - Health Endpoint: `http://127.0.0.1:8000/api/health`

## 🌐 Step 2: How to Deploy on Render & Get Your Render URL

To get a **live Render URL** (e.g. `https://python-render-showcase.onrender.com`):

### Option A: Using Render Dashboard (Recommended)

1. **Push your code to GitHub:**
   - Create a repository on GitHub (e.g. `python-render-demo`).
   - Commit & push your project files (`app.py`, `requirements.txt`, `Procfile`, `render.yaml`, `runtime.txt`).

2. **Sign up / Log in to [Render.com](https://render.com):**
   - Click **New +** -> **Web Service**.

3. **Connect Repository:**
   - Select your GitHub repository (`python-render-demo`).

4. **Configure Web Service:**
   - **Name:** `python-render-showcase` (or any unique name)
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app:app --host 0.0.0.0 --port $PORT`
   - **Instance Type:** `Free`

5. **Deploy!**
   - Click **Create Web Service**.
   - Render will build and deploy your pure Python app in seconds.
   - You will receive your live Render URL at the top of the dashboard:
     ```
     https://python-render-showcase.onrender.com
     ```

---

### Option B: 1-Click Blueprint Deploy (`render.yaml`)

Because this project includes a `render.yaml` file, you can also deploy it via Render Blueprints:
1. Go to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** -> **Blueprint**.
3. Connect your GitHub repository.
4. Render automatically reads `render.yaml` and deploys your web service!

## ⚡ Features Included in `app.py`

- **Dynamic Glassmorphism Dark UI**: Beautiful responsive user interface served directly by Python.
- **`GET /`**: Main Interactive Web Dashboard.
- **`GET /docs`**: OpenAPI (Swagger) documentation automatically generated by FastAPI.
- **`GET /api/health`**: JSON endpoint reporting server status, uptime, and environment metrics.
- **`GET /api/analytics`**: Real-time statistical analysis performed purely in Python.
